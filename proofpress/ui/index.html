Keywords

  
The writer only ever picks topics from this list, highest priority first. Rows that share a cluster become one article, not several competing pages.

  

    
CSV format

    
keyword,cluster,priority,intent_hint,status,slug,published_at,notes
best plant watering app,apps,1,buying guide,todo,,,"secondaries: plant care app"
plant watering schedule template,schedules,1,list (download),todo,,,
how often to water succulents,care,2,how-to,todo,,,

    
    
      
  • keyword: required, the exact search phrase. Header row required; only "keyword" is mandatory.
    • 
      
  • priority: 1 (highest) to 3. intent_hint: buying guide, comparison, how-to, definition, troubleshooting, list, list (download).
    • 
      
  • status: todo, drafting, approved, published, blocked, skip. Leave slug and published_at empty; the pipeline fills them.

Go live on AWS

  
Give your domain, connect your AWS account once, and ProofPress builds the hosting for you: a private S3 bucket, an HTTPS certificate, a CloudFront CDN, DNS records and the first upload. Everything is created in your own AWS account; costs are usually under a dollar a month for a small site.

  
The AWS SDK isn't installed. Run ./install.sh again (it installs boto3), then restart this page.


  

    
1 · Connect your AWS account

    

      
      
    

    

      

        How to get access keys (about 3 minutes, once)
        
    
          
  1. Sign in to AWS (create a free account first if you don't have one), then open IAM > Users > Create user. Name it proofpress. Open IAM
    2. 
          
  2. Permissions: choose "Attach policies directly" > "Create policy" > JSON tab, paste the policy below, save it as ProofPressPolicy, and attach it to the user. 
    3. 
          
  3. Open the user > Security credentials > Create access key > "Application running outside AWS". Copy both values into the boxes below.
    4.

Action needed at your DNS provider
Your domain's DNS isn't in Route 53, so add these records where you manage DNS (GoDaddy, Namecheap, Cloudflare, Alibaba Cloud...). Setup continues by itself once they take effect. Many providers want only the first part of the name (without your domain at the end); they add the domain themselves.

      
ForNameTypeValue

      
If the site domain is a bare domain (example.com, no www) and your DNS provider can't put a CNAME on it, use www.example.com as the site domain instead, or move DNS to Route 53.

    Secrets
    
  
    API keys and passwords for publishing. They're stored only on this computer in the project's .proofpress folder (which git ignores) and are never shown again in full. An environment variable with the same name always takes priority.
    
  
    

    



    
  
    Quality gate
    
  
    Every draft is scored on a 100-point rubric by a reviewer that didn't write it. Hard fails (invented product claims, unverified YMYL claims, made-up stats, wrong intent, scanner failures) fail the draft regardless of score.
